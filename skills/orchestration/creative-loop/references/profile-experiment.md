# Profile: experiment

Used when the adapter's `profile` is `experiment` (lab: an app under `apps/experiments/`): an animated or interactive piece that is watched or played with, not won. No game rules apply.

## Each direction

- When something reacts to input or time, its response is visible within the same frame window the brief names; name in the cycle line what reacts and how.
- Sound only when the brief asks for it; then build it with the lab's audio mixer and synth recipes, and say in the cycle line that it has not been heard.

## Review cycle

Check the fresh shots against the brief's pillars, look direction and Not this list, in that order, then name the three weakest things a viewer would notice in the first ten seconds and one thing to remove or simplify (an effect, a control, an overlay that costs more attention than it gives). Run the UI pass ([ui-pass.md](ui-pass.md)) on any controls, labels or overlays the piece has; with none, the pass is the screens sheet alone.

## Hand-off

The summary's **Play it** links include the start and one link per state worth seeing, from the app's own URL parameters, and **Controls** lists the inputs the piece responds to. The run-article frame is one demo second at the piece's strongest moment.
