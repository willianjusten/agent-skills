# Experiment mode

An experiment has no win state, so there is no twist round or verb test; in the pitch, its "Core verb and input" is the main input and its twist is `n/a`. Ask these rounds, with a recommendation each.

1. The feeling: one sentence ("a held breath", "slow static"), not a description of visuals.
2. Where and how: shown where, on what device, how long, with or without sound.
3. Input to motion: for each input (pointer, scroll, time, audio), what moves and how (direction, easing character, scale). Also: what happens with no input, and with reduced motion.
4. Directions: two or three that differ in feeling or motion character, not in color. Recommend one; note the others as rejected.
5. Scope: how long it runs, how many distinct states or scenes, what sound or content it needs; recommend the smallest version that keeps the feeling and give an ordered cut list of three.
6. "Not this": at least five concrete defaults to avoid (a generic gradient, bouncy ease, vignette on everything, particle confetti). Each must be checkable by looking at a frame.
