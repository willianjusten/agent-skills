# Piece mode

A piece has no win state. Ask these rounds, with a recommendation each.

1. The feeling: one sentence ("a held breath", "slow static"), not a description of visuals.
2. Where and how: shown where, on what device, how long, with or without sound.
3. Input to motion: for each input (pointer, scroll, time, audio), what moves and how (direction, easing character, scale). Also: what happens with no input, and with reduced motion.
4. Directions: two or three that differ in feeling or motion character, not in color. Recommend one; note the others as rejected.
5. "Not this": at least five concrete defaults to avoid (a generic gradient, bouncy ease, vignette on everything, particle confetti). Each must be checkable by looking at a frame.
