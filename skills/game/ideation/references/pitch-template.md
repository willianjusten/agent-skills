# Pitch template

Save as `PITCH.md`. One page (about 60 lines), engine-neutral. Write `n/a` in sections the mode does not use. "Approved by" stays empty until the user approves, then gets their name and the date.

```markdown
# <Working title>

**Mode:** game | experiment
**One sentence:** <the idea>
**Feeling:** <target feeling>

## Fantasy (game) / Feeling in motion (experiment)
<You are ___ doing ___, and the mechanics that deliver it. / the sentence>

## Core verb and input
<verb, input, verb-test result; for an experiment, the main input and `n/a` for the verb test>

## Loop (game)
- 30 seconds:
- 5 minutes:
- Session:

## Input to motion (experiment)
<mapping, no input, reduced motion, sound if any>

## Twist
<Like X, but ___.>

## Scope
<who plays and the first minute, the smallest version, ordered cut list of three (first cut first)>

## Not this
<five or more concrete items>

## Rejected concepts and directions
<one line each: concepts, directions, and any rule or recommendation the user rejected>

## Open questions
<at most three>

**Approved by:** <name, date, empty until approved>
```
