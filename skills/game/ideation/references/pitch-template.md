# Pitch template

Save as `PITCH.md`. One page, engine-neutral. Write `n/a` in sections the mode does not use. "Approved by" stays empty until the user approves.

```markdown
# <Working title>

**Mode:** game | piece
**One sentence:** <the idea>
**Feeling:** <target feeling>

## Fantasy (game) / Feeling in motion (piece)
<You are ___ doing ___. / the sentence>

## Core verb and input
<verb, input, verb-test result>

## Loop (game)
- 30 seconds:
- 5 minutes:
- Session:

## Input to motion (piece)
<mapping, no input, reduced motion>

## Twist
<Like X, but ___.>

## Scope
<smallest version, ordered cut list of three>

## Not this
<five or more concrete items>

## Rejected concepts and directions
<one line each>

## Open questions
<at most three>

**Approved by:** <name, date, empty until approved>
```
