# Core verb, verb test and loop

## Core verb
The one action the player does most (jump, cut, tether, merge). Name it as a verb, not a feature. If two verbs compete, pick one; the other becomes support or is cut.

## Verb test
Imagine the verb with no score, reward, level or enemy. Is it still pleasant for ten seconds (Schell's toy lens: is it fun to play with, apart from any goal)? If no, the game needs a different verb or a toy-first round (see toy-first.md), not more rewards.

## Loop at three scales
- 30 seconds: the moment-to-moment cycle (act, feedback, adjust). What does the player decide?
- 5 minutes: the goal that groups cycles, its challenge and its payoff. What changes between cycles?
- A session: what keeps the player going, what ends it, what carries to the next session (or nothing).

Each scale gets one or two sentences. If a scale has no decision, flag it as a gap and ask the user how to fill it.

## Surprise
Schell's surprise lens: name one thing in the loop the player will not predict the first time. If none, note it.
