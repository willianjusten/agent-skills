# Player fantasy, from feeling back to mechanics

Source: Hunicke, LeBlanc and Zubek, "MDA: A Formal Approach to Game Design and Game Research" (2004). Designers build Mechanics, which run as Dynamics, which the player experiences as Aesthetics; players meet them in the opposite order, so design from the end.

1. Aesthetics: pick one or two target feelings from the paper's taxonomy (sensation, fantasy, narrative, challenge, fellowship, discovery, expression, submission) or the user's own words. Ask: "after ten minutes, what should the player say they felt?"
2. Player fantasy: one sentence, "You are ___ doing ___", that carries the feeling.
3. Dynamics: which behaviors would produce that feeling (hoarding, risk-taking, improvising, rushing and recovering)? List two or three.
4. Mechanics: the smallest set of rules and verbs that would make those dynamics appear. Stop at three.
5. Check backward: would these mechanics plausibly produce the feeling, or something else? Name the risk.

Output for the pitch: the target feeling, the fantasy sentence, the dynamics wanted, the mechanics chosen.
