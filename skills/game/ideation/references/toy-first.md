# Toy first (optional)

Use when the verb test is unclear or the user cannot say if the core interaction feels good. Skip when the verb is a known quantity.

1. Pick the single core interaction (the verb plus its input).
2. Build the smallest throwaway prototype of it: no goal, score, fail state, menu or art beyond shapes. If a prototyping skill is installed, use it; otherwise write the smallest runnable page yourself.
3. Ask the user to play with it for a minute and answer: what did you try to do that it did not allow? what did you repeat without being asked?
4. Fold the answers back into the verb and the loop. Delete the prototype or mark it throwaway.

Done when the user can say whether the verb is worth building a game around.
