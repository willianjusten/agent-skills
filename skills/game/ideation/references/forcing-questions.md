# Twist and scope

Borrowed ideas only: forcing questions that make a concept state what is new and what is affordable.

## Twist against comparables
1. Name the two or three closest existing games (ask the user; research if unsure).
2. For each: what do they do that this game also does? What does this game do differently in the verb, the fantasy or the constraint?
3. Finish: "Like X, but ___." The blank must change play, not theme. If it only changes theme, say so and ask for a mechanical difference.

## Forcing questions
- Who plays this, where, for how long?
- What is the first minute?
- What is the one thing that would make a player tell someone about it?
- What would you cut first if time halved?

## Scope check
Estimate in rough sizes (days, weeks): content needed, systems needed, art and sound needed. Flag anything that grows with content (levels, items, enemies). Recommend the smallest version that still delivers the target feeling and state the ordered cut list in three items. If it does not fit, propose a cut now, not later.
