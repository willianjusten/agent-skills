# Pre-flight

Run before the concept rounds, in order. Each test exists because a plausible idea can pass every later round and still be generic, a copy, or a gimmick.

1. **Prior art.** Name the two or three closest existing games or pieces (ask the user; research if unsure). For each, one line to take and one line to leave. Done when every comparable has both lines.
2. **Promise sentence.** One sentence: what the player or viewer gets and feels. Restate test: ask a fresh reader (or yourself, cold) to restate it in their own words; if the restatement differs in substance, rewrite the sentence. Done when the restatement matches.
3. **Too-generic test.** Swap in a different theme or subject. If the promise still reads true unchanged, it is generic: ask for the specific thing only this idea does and rewrite the promise.
4. **Real-axis options.** When showing options (concepts, directions, looks), generate more than you show and cull before showing. Options must differ on a real axis (verb, constraint, feeling, motion character), never only on theme, color or name. Show two or three, recommend one. Done when no two shown options share their axis.
5. **Gimmick-off test.** Remove the novel hook in your head. If what remains is not worth making, the hook is carrying the idea: strengthen the base or say so. Done when the idea survives without its hook, or the user knowingly accepts that it does not.
