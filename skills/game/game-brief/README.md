# Game Brief

Turns a game concept into a GDD, treatment and art bible before any code.

## What It Does

| Phase | Output |
| ----- | ------ |
| GDD | Pillars, core loop, controls, scope, cut list, non-goals, feature list with checks, balance band |
| Treatment | Idea, palette, camera, input mapping, "Not this" list |
| Art bible | Palette, references, style rules, asset level and polish per asset type |
| Engine stub | `ENGINE.md` and optional nested `AGENTS.md` |

## Usage

```text
Write a brief for a one-button arcade game about a lighthouse keeper
Make a GDD and art bible for a 3-minute dodge game
What should I cut from this game idea?
```

## Output

`GDD.md`, `TREATMENT.md`, `ART-BIBLE.md`, `ENGINE.md` in the app folder.
