# <Title> art bible

Signed off by the user before any asset beyond a placeholder is made.

## Theme and setting

One line (for example "pirate cove, night"). Packs are picked against it.

## Asset source

One pack family (for example Kenney or Quaternius) for models, plus libraries for textures; or `code-only`: every asset made by code, no asset files.

## Palette

Hex values and roles; must match the treatment.

## References

Three to six: a link or file, and the one thing to take from each.

## Style rules

Shape language, texture detail, lighting mood, outline or none, and what to avoid.

## Style test sheet

Path to the sheet: one subject in the target style at the chosen detail, shown before bulk work. Status: pending or approved, with date.

## Asset levels

| Asset type | Level | Polish | Notes |
| ---------- | ----- | ------ | ----- |
| Textures | placeholder / free / premium | rough / polished | |
| Sprites and cutouts | | | |
| 3D models | | | Pack family, or code-made |
| Sound effects | | | |
| Music | | | |

Level is how much may be spent; polish is how much effort per asset. Default to placeholder and rough. Premium stays locked until the user unlocks it.

## Sign-off

Name, date, and anything the user changed.
